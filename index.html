Before you begin

  • The profile heatmap covers the last 365 days only. Commits dated in 2020 will not change today's grid squares; they appear under Contribution activity on your profile for that calendar year.
  • Back-dating is additive. The script creates new commits on top of your default branch head; it never deletes history, overwrites existing commits, or resets your repository.
  • Use a dedicated repository (e.g. username/activity). Do not spam commits into a repository with active GitHub Actions workflows.

Setup & Installation

Target repository must have at least one initial commit (e.g. README.md) Target Repository Requirement: The target repository cannot be completely empty (0 commits). The GitHub REST Git Database API requires an existing initial commit (the default branch head) as a parent reference to create new commits on top of it. Check the "Add a README file" option when creating your repository.

Download the atomic script directly:

curl.exe -O https://raw.githubusercontent.com/arhylsion/ghgraph/main/ghgraph.py

Export your Personal Access Token:

$env:GITHUB_TOKEN = "ghp_your_token_here"

Examples

You can preview any plan before touching GitHub by adding the --dry-run flag.

1. Natural activity spread

Distribute 40 commits across June–December 2024, and 80 commits across 2025 with organic weekday weighting:

python ghgraph.py --repo user/activity --spread "2024-06-01..2024-12-31:40, 2025-01-01..2025-12-31:80"

2. Fill empty days only

Skip dates that already have contributions by querying your contribution calendar with GraphQL:

python ghgraph.py --repo user/activity --spread "2025-01-01..2025-12-31:80" --only-empty

3. Full year fill

Generate 2 commits every weekday of 2020:

python ghgraph.py --repo user/activity --year 2020 --per-day 2 --skip-weekends

4. Specific dates

Pin explicit commit counts on individual days:

python ghgraph.py --repo user/activity --dates "2020-05-04:5, 2020-05-06:2"

5. 5×7 Text banner

Render a text banner starting from a specific Sunday:

python ghgraph.py --repo user/activity --text "HELLO" --start 2020-03-01

6. Local git repository backend

Create empty commits in a local checkout and push in a single git command instead of making HTTP requests:

python ghgraph.py --backend git --path C:\code\activity --dates "2020-05-04:3"

How GitHub Shading Works

GitHub does not map fixed numbers of commits to fixed shades of green. The four shades are quantiles calculated relative to your busiest day in that rolling calendar period.

If your busiest day has only 1 commit, all active days will render in the lightest shade. To ensure visual contrast for text banners and pixel patterns, use --scale 2.0 to raise the upper commit counts.

Command Line Reference

Option Default Description
--repo OWNER/NAME — Target GitHub repository for the API backend.
--token TOKEN $GITHUB_TOKEN Personal Access Token with repository write permissions.
--backend {api,git} api Use api (no clone) or git (local repository).
--path PATH . Local clone directory when using --backend git.
--spread "S..E:N" — Distribute N commits randomly across the specified date range.
--year YEAR — Fill all days of a calendar year (e.g. 2020).
--range START..END — Date interval to populate (e.g. 2020-01-01..2020-06-30).
--dates "D:N,..." — Exact days with commit counts (e.g. 2020-05-04:3).
--text "..." — 5×7 pixel text banner (A–Z, 0–9).
--pattern FILE — Custom 7-line art file (Sunday to Saturday).
--per-day N 1 Commits per day for --range and --year.
--skip-weekends false Exclude Saturdays and Sundays from commit schedules.
--only-empty false Skip days that already have contributions via GraphQL query.
--hour N 12 Hour of day for commits (0 to 23).
--jitter N 30 Random time variance in minutes around the specified hour.
--tz OFFSET +00:00 Timezone offset for commit timestamps (e.g. +07:00).
--dry-run false Preview scheduled commits in terminal without sending data.
-y, --yes false Skip the interactive confirmation prompt.

Why a commit might not appear

If commits are pushed successfully but do not appear on your profile graph, check the following criteria:

  1. Default branch: Commits only count toward your graph if they are on the repository's default branch (or gh-pages).
  2. Author email: The commit author email must match an email address linked and verified on your GitHub account. The script defaults to your GitHub id+username@users.noreply.github.com address.
  3. Forks are excluded: GitHub does not count contributions made to repository forks. The repository must be standalone.
  4. Private contributions setting: If the repository is private, enable "Include private contributions on my profile" in your profile settings.
  5. Future dates: GitHub ignores commits with timestamps in the future. The script automatically skips future dates.

Workflow Setup Guide

Include Private Contributions (PAT Setup)

  1. Create a Token on Your GitHub Account
    • Open Settings (top-right profile menu) → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic).
    • Give it a name (e.g. HEATMAP_TOKEN), choose an expiration, and check the read:user (or repo) scope.
    • Click Generate token and copy the token value.
  2. Save the Token in Repository Secrets
    • Open your profile repository on GitHub (username/username).
    • Go to Settings → Secrets and variables → Actions in the left sidebar.
    • Click New repository secret.
    • Set Name to GH_PAT (do not use GITHUB_TOKEN, as it is reserved by GitHub).
    • Paste your token into the Secret field, then click Add secret.
  3. Update Your .yml Workflow File

    Use ${{ secrets.GH_PAT }} and pass --private (or switch Workflow Scope to Public + Private (PAT) in the Studio to generate it automatically). Use --public if you want public contributions only:

          - name: Generate Animated Heatmap Cards
        env:
          GITHUB_TOKEN: ${{ secrets.GH_PAT }}
        run: |
          curl -sSL -O https://raw.githubusercontent.com/arhylsion/ghgraph/main/ghgraph.py
          python3 ghgraph.py --card --username ${{ github.repository_owner }} --theme both --private --output assets/
          rm -f ghgraph.py
